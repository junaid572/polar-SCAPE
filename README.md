# polar-SCAPE

Simulation code for "Shannon Meets Cramér–Rao: Near-Limit Communication and Parameter Estimation over Pauli Channels". These scripts generate the data behind the figures of the manuscript.

## Setup

- Python 3 with the packages in requirements.txt
- Run all scripts from the repository root
- polar_codes/: polar code library (PW construction, SC/SCL decoding, CRC-8/16), adapted from https://github.com/RQC-QApp/polar-codes (MIT license, see polar_codes/LICENSE). Constructions are computed on first use and cached under polar_codes/polar_codes_constructions/
- DWC_F.py: helper functions for Pauli channels (parameters, capacities)
- bsc_polar.py: one polar block over a BSC (encode, transmit, SCL decode with list size 32, re-encoding BER). bsc_polar16 / bsc_polar8 / bsc_polar0 use CRC-16 / CRC-8 / no CRC

## File/Figures Descriptions

- 20250717_bsc_polar_top-ber-vs-codeRate.py: BER vs. code rate over a BSC; writes polar0_n{n}_p{p}.dat. Fig. 1 uses (n, p) = (9, 0.01) and (9, 0.1)
- [20250828] CRB.py: For generating Fig. 3. Prints the EFPE total error and the bound
- 20260901_V1_Fig3_Fig4_data_generation.py: Polar SCAPE estimation at a fixed channel (gamma = 0.8). Prints the polar SCAPE values of Fig. 3 and writes fix_channel2_R2.dat for Fig. 4. Target rates are fractions (0.6, 0.45, 0.4) of capacity, lowered to (0.535, 0.36, 0.34) at n = 8
- 20250805_V3_Percent_Estimate_no_plotting.py: To get communication (percentage of capacity) data of Fig. 4. Decreases k by one on each unreliable block until 1000 blocks in a row are reliable
- 20250730_V2_N_vs_DND_parallel.py: To get estimation data of Fig. 4
- 20250722_V8_SCL_Data_Generation_Polar_Code.py: To generate data for Figure 5, 6, and 7 of the manuscript. Rate-adaptation hyper-parameters (inc_perc, dec_perc, inc_after, inc_wait, targets) are set at the top of the main loop
- 20250722_V5_Data_Processing_Polar_Code.py: To process the data generated by the above file. Set write_file = True to write the .dat files
- 20260120_SCL_timing.py: Timing vs. N; writes polar_timing_results.txt (Fig. 8)
- 20260120_SCL_timing_V2.py: Timing vs. k at N = 1024; writes polar_timing_vs_k.txt (Fig. 8)
- 20260106_Comparison_PTA_AD.py: Compares the Holevo Information and Fisher Information of Amplitude Damping channel with Pauli Twirled Approximation of Amplitude damping channel. (Not included in the paper)
